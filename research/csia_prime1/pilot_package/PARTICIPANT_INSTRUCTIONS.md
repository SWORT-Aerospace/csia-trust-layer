# Participant instructions

**Thank you for taking part.** This session tests whether an analysis tool
helps engineers reason about PX4 flight logs. **It tests the tool, not you.**

## 1. What you have

| item | what |
|---|---|
| `logs/P01.ulg` ... `logs/P12.ulg` | twelve PX4 flight logs |
| `LOGS.json` | for each log, only whether it is a SITL (simulation) or a REAL log |
| `install/` | the analyzer (`QUICKSTART.md`) |
| `QUICKSTART.md`, `REPORT_GUIDE.md`, `KNOWN_LIMITATIONS.md`, `SUPPORT_MATRIX.md` | how to run and read the analyzer, and its limits |
| `DIAGNOSTIC_QUESTIONS.md` | the answer sheet, one copy per log |
| `FEEDBACK_FORM.md` | to fill in at the end |
| `DATA_NOTICE.txt` | where the logs come from |

**Some simulated logs contain injected faults of different kinds; some
contain none.** The file names and the order of the logs say nothing about
their content.

## 2. How the session runs

1. The experimenter tells you, **for each log, whether you may use the
   analyzer**. Without it, use your usual tools (Flight Review, PlotJuggler,
   pyulog, your own scripts, the PX4 documentation).
2. **Use one answer sheet per log.** Note your start and end time.
3. **Answer from the log, not from what you expect.** "Cannot tell from this
   log" is a valid answer and is scored as correct where it is correct.
4. Give no numerical confidence. Choose the certainty box instead.
5. **The experimenter can help you run the tools, but cannot comment on a
   log.**
6. At the end, fill in the feedback form.

## 3. Your data

- Your answers are scored by two raters who do not know which tool you used
  for which log.
- Nothing you write is used to identify you in any report.
- Do not share the logs outside the session.
