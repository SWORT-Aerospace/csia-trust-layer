## 3. SEQUENTIAL CONFIGURATION

| | |
|---|---|
| statistic | one-sided CUSUM, `S_t = max(0, S_{t-1} + z_t - k)`, alarm `S_t > h` |
| residual | `z_t = (lam_t - mu0) / sigma0` on the **pre-transform** smoothed chi-square |
| **k** | **0.5** — textbook, set by design |
| **h** | **500** — smallest grid value with zero clean-arm alarms |
| gating | a gated-out or stale sample is skipped; the statistic is neither advanced nor reset |
| covered nodes | `battery`, `gps`, `mag`, `motor_esc`, `vibration` — **five** |
| no residual | `baro` (clean σ₀ degenerate), `imu0`, `imu1` (**no per-IMU chi-square exists**) |
| state | one float per covered node — 5 floats, 40 bytes |

In-control statistics are **frozen constants**, derived from the clean arm and
from nowhere else. They are not re-estimated at runtime: an in-control
statistic re-estimated during a fault stops being in-control.

## 6. SUPPORT SEMANTICS — FROZEN

Structural, no tuned threshold. From `SUPPORT_STATE_SPEC.md`:

- a term is **discriminating** for a pair iff it is gated in, the hypotheses
  disagree about it in `CAUSES`, and `c ≠ 0.5` (the core's own likelihood
  indifference point);
- a leader is **identifiable** iff at least one active discriminating term
  exists against **every** other modeled hypothesis;
- `ambiguity` is `UNIQUE` iff identifiable, `AMBIGUOUS` otherwise — **never a
  posterior margin**;
- `prior_sensitive` iff the leader changes under a uniform prior on the same
  evidence.

Support state, a total function of three booleans:

    NO_APPLICABLE_EVIDENCE | NON_IDENTIFIABLE | PRIOR_SENSITIVE | EVIDENCE_BACKED

`TAU_NUM = 1e-12` is a float comparison tolerance, not a threshold; the
verdict is identical across `[1e-15, 1e-9]`.

**Support metadata never modifies the production posterior.** A test asserts
the posterior is bit-identical with and without the analysis.

## 7. CANONICAL INGESTION SEMANTICS — FROZEN

`CANONICAL_INGEST_SPEC.md` rules R1–R5:

| | |
|---|---|
| **R1** supersession | a producer's most recent statement about a channel wins, in **both** directions — a sentinel supersedes an earlier value, not only the reverse |
| **R2** reason fidelity | when a channel is absent, the reported reason is the producer's own: `NOT_RECEIVED` / `STALE` / `SENTINEL` / `NO_3D_FIX` |
| **R3** no fabrication | a sentinel is never converted into a number |
| **R4** independent constituents | fields carried in one message are qualified independently |
| **R5** sentinels age | a sentinel is a statement about a moment and goes stale like a value |

`current_valid` accompanies `current` on every battery path; its versioning is
Phase 4 (§28) and is carried in the output schema.
